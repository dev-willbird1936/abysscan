# Code of conduct

This is a small hackathon project. Be decent.

- Do not harass anyone who files an issue, a pull request or a security report.
- Do not post malware samples, exploit payloads, or instructions for building malware.
- Security problems go through [private vulnerability reporting](https://github.com/dev-willbird1936/abysscan/security/advisories/new), not a public issue.

Reports about conduct: **willbird1936@gmail.com**.
