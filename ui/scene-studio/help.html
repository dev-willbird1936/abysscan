Scene Studio guide

Write one fictional scene, then preview it on Windows and macOS. These scripts change the training world only. They never execute programs on your computer.

Write → check → play

  1. Open Scene Studio and choose an example. Press Load example.
  2. Change the title, fictional user and explanations. Each step needs a look hint, an explanation beginning with |, and an action that changes the desktop.
  3. Press Check script. An error identifies the command and line to fix.
  4. Press Preview scene or Ctrl/⌘ + Enter. Sign in to the fictional account; no password is needed. Use Start, Next and Back, or switch operating systems.
  5. Use Download .scene to keep the script. Your draft also stays in this browser. Preview links expire on restart or after 20 newer previews.

Commands you will use most

title, os, user, theme
Set these before the steps. Use windows or macos and dark or light.
step, look, |
Name the step, tell the trainee where to look, and explain what changed. Finish the scene with lesson and its explanation.
mail, page, file, open
Create a fictional message, web page or file, then open an app or named item. Use .example or .invalid domains, not real accounts.
run, block, startup
Show a simulated process, blocked connection or startup entry. These are world changes, not executable commands.
encrypt, delete, rename, homepage
Illustrate changes to pretend files or browser settings. No host files change.

Use Insert an action and Script reference inside the editor for exact syntax and ready-to-use snippets. Keep the scene short and focus on one lesson.
